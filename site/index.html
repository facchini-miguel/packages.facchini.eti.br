Pacotes Linux

Repositório de pacotes (apt, dnf e zypper) do software de Miguel Facchini. Hoje: o Kaladrius, para servidores com processador Intel ou AMD de 64 bits.

Com o repositório adicionado, as versões novas chegam com as atualizações do próprio sistema (sudo apt upgrade, sudo dnf upgrade ou sudo zypper update). Antes de instalar, veja os sistemas aceitos e as perguntas da instalação.

Debian 13+ e Ubuntu 24.04+

sudo apt install -y curl ca-certificates
sudo install -d -m 0755 /etc/apt/keyrings
sudo curl -fsSLo /etc/apt/keyrings/facchini.asc https://packages.facchini.eti.br/chave.asc
echo "deb [arch=amd64 signed-by=/etc/apt/keyrings/facchini.asc] https://packages.facchini.eti.br/deb stable main" | sudo tee /etc/apt/sources.list.d/facchini.list
sudo apt update
sudo apt install kaladrius

As perguntas da instalação aparecem na hora.

Fedora, Red Hat Enterprise Linux, Rocky Linux e AlmaLinux

sudo curl -fsSLo /etc/yum.repos.d/facchini.repo https://packages.facchini.eti.br/rpm/facchini.repo
sudo dnf install kaladrius
sudo kaladrius configurar

No Red Hat, Rocky e AlmaLinux, acrescente antes o repositório do Docker.

openSUSE

sudo zypper addrepo https://packages.facchini.eti.br/rpm/facchini.repo
sudo zypper install kaladrius
sudo kaladrius configurar

A chave

Os repositórios e os pacotes .rpm são assinados com a chave de impressão digital:

9D3A 0438 FF6C 00F9 1CA1 A0AB A5C3 35B2 EB36 7ABA

O dnf e o zypper mostram essa impressão digital antes de confiar na chave: confira se é a mesma.
